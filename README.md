# 🥗 FoodKeeper — Умный PWA трекер питания и холодильник

> **FoodKeeper** — мобильно-ориентированное PWA-приложение для умного контроля питания, учёта продуктов в холодильнике, сканирования этикеток через ИИ (Gemini Vision) с поддержкой прокси, подбора рецептов и генерации сбалансированного меню на 7 дней (4 приёма пищи в день).

---

## ✨ Ключевой функционал

- 📊 **Дневной КБЖУ Dashboard**: Анимированное кольцо прогресса калорий, трекер БЖУ (белки, жиры, углеводы), интерактивный график динамики веса и чекбоксы 4 приёмов пищи.
- 🧊 **«Холодильник»**: Инвентарь продуктов по категориям (молочка, мясо, рыба, овощи/фрукты, бакалея) со сроками годности, цветовой индикацией и быстрым контролем остатков.
- 📷 **«Магазин» / Сканер этикеток**: Мультимодальный ИИ-сканер (Gemini Vision) — распознает название, вес, срок годности и таблицу КБЖУ с фото этикетки или упаковки.
- 🛡️ **Прокси для Gemini API**: Настраиваемый шлюз/прокси прямо в настройках приложения для обхода региональных ограничений (User location is not supported).
- 🧑‍🍳 **Рецепты из холодильника**: Умный мэтчинг блюд с расчётом процента ингредиентов в наличии, пошаговыми инструкциями и списанием продуктов при готовке.
- 🌐 **Импорт рецептов из интернета**: Парсинг открытых кулинарных ссылок или произвольного текста через ИИ с расчётом КБЖУ на порцию.
- 📅 **Меню на неделю (4 приёма в день)**: Генерация 28 сбалансированных приёмов пищи под суточные нормы калорийности и автоматический список покупок.
- 📱 **PWA & Мобильный UX**: Поддержка установки на экран смартфона (iOS/Android), светлая и OLED тёмная темы, плавные анимации Framer Motion.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка production версии (PWA)
npm run build
```

---

## 🛠️ Стек технологий

- **Frontend**: React 19, TypeScript, Vite
- **Стилизация**: Tailwind CSS, Lucide Icons, Framer Motion
- **Хранение данных**: Local-first IndexedDB (Dexie.js)
- **ИИ-интеграция**: Google Gemini API (Vision OCR, NLP) с поддержкой кастомного Proxy URL
- **PWA**: vite-plugin-pwa, Service Worker, Offline Support
